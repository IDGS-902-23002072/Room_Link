# RoomLink visual assets

- `explore-interior.png`: original AI-generated architectural illustration for RoomLink (November 2026). Decorative promotional image, not a real property listing.
- `roomlink-mark.png`: original AI-generated RoomLink mark concept. The favicon is a compact vector implementation of the linked-home concept.
- Optional hero video: Gustavo Fring, "Couple Checking Out an Apartment", Pexels: https://www.pexels.com/video/couple-checking-out-an-apartment-7424438/

The video preloads from Pexels on arrival. The carousel shows the local image until playback is ready, then transitions into muted inline playback. When the video ends, the image returns for seven seconds before the cycle repeats. Visitors can pause or select a slide. Leaving the hero or hiding the tab suspends playback and timers. Reduced motion disables automatic cycling unless explicitly resumed. The local image remains available if loading or autoplay fails.
